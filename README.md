# Customer Review Analytics for Restaurants

## About the Project

This is a non-commercial student research project focusing on customer experiences and expectation-experience disconfirmation in restaurant reviews.

## Research Objectives

The project aims to investigate how customer expectations influence evaluations of restaurant experiences, including cases where positive experiences fall short of expectations.

## Data Sources

The research evaluates restaurant review data from Google Maps and potential additional sources, including Tripadvisor, subject to applicable data access and usage permissions.

## Research Methods

- Restaurant review data collection
- Data preprocessing and quality validation
- Natural language processing
- Expectation-experience disconfirmation annotation
- Customer experience analysis

## Project Status

Ongoing academic research. This repository provides a public overview of the project. Research data and private materials are not published here.
